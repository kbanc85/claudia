## Task 3: Commitment resolver — implementation

**Files:**
- Modify: `memory-daemon/claudia_memory/services/consolidate.py` (add `resolve_commitments()` near `run_lifecycle_transitions()`)
- Modify: the config module (add knobs, mirroring `cooling_threshold_days` pattern): `commitment_grace_days=14`, `commitment_stale_days=60`, `commitment_stale_importance_ceiling=0.5`, `commitment_resolver_enabled=True`.

Implementation sketch (adjust to actual config/db API after reading neighbors):

```python
def resolve_commitments(self) -> dict:
    """Archive commitments that expired or went stale. Never delete (Prop 12 D5).

    expired: deadline passed more than grace-period ago, not recently accessed.
    stale: no deadline, old, unreferenced, low importance.
    Sacred and invalidated rows are never touched. metadata.resolution records why,
    metadata.resolved_at records when, so the briefing can disclose and the user can correct.
    """
    if not self.config.commitment_resolver_enabled:
        return {"expired": 0, "stale": 0}
    now = datetime.utcnow()
    grace_cutoff = (now - timedelta(days=self.config.commitment_grace_days)).isoformat()
    stale_cutoff = (now - timedelta(days=self.config.commitment_stale_days)).isoformat()
    access_cutoff = grace_cutoff  # reuse: "recently accessed" = within grace window

    # expired
    self.db.execute("""
        UPDATE memories
        SET lifecycle_tier='archived', archived_at=datetime('now'), updated_at=datetime('now'),
            metadata=json_set(COALESCE(metadata,'{}'), '$.resolution', 'expired',
                              '$.resolved_at', datetime('now'))
        WHERE type='commitment' AND invalidated_at IS NULL
          AND lifecycle_tier NOT IN ('sacred','archived')
          AND deadline_at IS NOT NULL AND deadline_at < ?
          AND (last_accessed_at IS NULL OR last_accessed_at < ?)
    """, (grace_cutoff, access_cutoff))
    # stale (no deadline)
    self.db.execute("""
        UPDATE memories
        SET lifecycle_tier='archived', archived_at=datetime('now'), updated_at=datetime('now'),
            metadata=json_set(COALESCE(metadata,'{}'), '$.resolution', 'stale',
                              '$.resolved_at', datetime('now'))
        WHERE type='commitment' AND invalidated_at IS NULL
          AND lifecycle_tier NOT IN ('sacred','archived')
          AND deadline_at IS NULL
          AND created_at < ? AND (last_accessed_at IS NULL OR last_accessed_at < ?)
          AND importance < ?
    """, (stale_cutoff, stale_cutoff, self.config.commitment_stale_importance_ceiling))
    ...return counts via rowcount, mirroring run_lifecycle_transitions error handling...
```

Follow the surrounding code's defensive style (try/except per statement, `logger.debug` on error, rowcount guards). Run the Task 2 tests → all PASS. Commit: `feat(memory): commitment resolver - expired/stale auto-archive (Prop 12 P2)`.
